Color

Drift check

Run after every change. It compares every eyebrow and button on a page with the shared definition, at 1920, 1536 and 390 wide.

cd bitgo-versions/shared/system
python partcheck.py sc-refokus                  # parts that differ from base.css
python partcheck.py sc-refokus --snap before.json  # save every part before a change
python partcheck.py sc-refokus --diff before.json  # list everything the change moved or restyled
