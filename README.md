# BitGo design

Concept redesigns of bitgo.com in three.js / WebGL: every homepage version, the product pages, the 3D model kit
(`shared/models/`) and the design system library (`library/`). Plain HTML, CSS and JS, no build step.

Live: https://bitgo-versions.vercel.app

Run locally: serve this folder with any static server, e.g. `python -m http.server 5173`, then open `index.html`.
